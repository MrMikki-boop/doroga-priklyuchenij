# Дорога приключений

Приключение для Foundry VTT 14 и dnd5e (минимум 5.3.3).

## Установка

В Foundry: «Дополнительные модули» → «Установить модуль». Ссылка манифеста:

https://github.com/MrMikki-boop/doroga-priklyuchenij/releases/latest/download/module.json

После установки можно выбрать приключение при создании мира. Содержимое импортируется автоматически; при первом входе ГМ активируется стартовая сцена и открывается руководство мастера. В существующем мире включите модуль и импортируйте приключение из библиотеки.

## Выпуск обновлений

1. Сохраните Adventure и закройте Foundry перед фиксацией базы библиотеки.
2. Измените `version` и версию в `download` внутри `module.json`. Ссылка `manifest` остаётся постоянной.
3. Закоммитьте и отправьте изменения в GitHub.
4. Создайте и отправьте тег, совпадающий с версией: например, для 1.0.9 — `git tag v1.0.9`, затем `git push origin v1.0.9`.
5. Workflow `.github/workflows/release.yml` проверит версию, соберёт ZIP и опубликует релиз с двумя файлами: `module.json` и архивом модуля. Уже опубликованные релизы не перезаписываются.

Локальная сборка: `powershell -NoProfile -File tools/build-release.ps1`. Результат находится в `dist`. Служебные файлы в архив не включаются.
